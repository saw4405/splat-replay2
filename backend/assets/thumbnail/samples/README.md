# 編集画面の固定サンプル

既存の実リザルト画面フィクスチャから作成した1920×1080の画像です。

| 同梱画像 | 元画像（backend/tests/fixtures/templates/） |
| --- | --- |
| result-1.png | battle_result_9.png |
| result-2.png | battle_result_20.png |
| result-3.png | battle_result_11.png |

プレイヤー名の領域を伏せています。キャラクター、背景、キル・デス・スペシャルの切り抜き領域は実画像を維持しています。
高キルレの切り抜きは生成本体と同じ座標・抽出条件で作成します。
マッチ種別・レート・勝敗などの集計値は表示確認用の固定データです。
このフォルダは素材一覧には表示しません。
