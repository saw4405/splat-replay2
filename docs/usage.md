# Splat Replay ユーザーガイド

この文書は、Windows 配布版の `SplatReplay.zip` と、Apple Silicon macOS 向け開発・検証用 DMG の利用者向けガイドです。
初回セットアップの細かい手順はアプリ内のセットアップウィザードに表示されるため、この文書では全体像と日常利用で迷いやすい点だけを扱います。

ソースコードからのビルドや開発環境構築は対象外です。

macOS 版は開発・検証用で、正式対応ではありません。実録画・編集・アップロードなど一部の利用者確認は済んでいますが、全機能の受け入れは未完了です。詳しくは[macOS 対応調査](macos_support_plan.md)を参照してください。

## 用意するもの

利用に必要なものは次の通りです。

- Windows 11 の PC、または検証用 macOS 版を使う Apple Silicon Mac
- Nintendo Switch とドック
- HDMI 入力対応のキャプチャーボード
- 安定したインターネット接続
- YouTube アカウント

使いたい機能に応じて、次も用意します。

- マイクと Groq API キー（文字起こしを使う場合）

## 使い始めるまで

Windows・macOS ともに、自動録画機能は初回セットアップ完了まで待機し、完了後はアプリを再起動せずに起動します。

### Windows

1. [GitHub Releases](https://github.com/saw4405/splat-replay2/releases) から最新の `SplatReplay.zip` をダウンロードします。
2. ZIP ファイルを、自分が書き込みできるフォルダへ展開します。
3. 展開したフォルダの `SplatReplay.exe` を起動します。
4. 初回起動時はセットアップウィザードが開くため、画面の案内に従って完了します。
5. セットアップが終わると、通常の利用画面に進みます。

通常画面へ進む前に、録画・判定・編集・YouTube アップロードに必要なソフトウェアと保存済み設定を確認します。不足がある場合は、起動時に不足項目と修復先のカードが表示されます。
Switch の電源や機器の一時切断、PC 要件の自己申告、一時的なネットワーク障害だけでは通常起動を止めません。文字起こしを使わない設定や、専用フォントがなく OS 標準フォントへ置き換わる場合も起動できます。

### macOS（Apple Silicon の開発・検証用）

1. [GitHub Releases](https://github.com/saw4405/splat-replay2/releases) に macOS 用 DMG が掲載されている場合は、それをダウンロードします。
2. Finder で DMG を開き、`SplatReplay.app` を `Applications` のエイリアスへドラッグします。
3. DMG を取り出し、「アプリケーション」から `SplatReplay.app` を一度開きます。
4. macOS が開発元を確認できないと表示した場合、配布元がこのプロジェクトの公式 Releases であることを確認してから、Apple メニューの「システム設定」>「プライバシーとセキュリティ」を開き、「セキュリティ」欄の「このまま開く」を選びます。表示された確認でログインパスワードを入力し、再度アプリを開きます。

「このまま開く」は、アプリを一度開こうとした後、およそ 1 時間だけ表示されます。Apple はこの操作が Mac の安全性を損なう可能性を案内しています。配布元を確認できない場合は許可しないでください。[Apple の手順](https://support.apple.com/guide/mac-help/mh40617/mac)も参照してください。

macOS 版は固定した自己署名証明書で署名し、公証されていません。初回起動で手動許可が必要になる場合があります。更新版も同じ署名主体を使いますが、Gatekeeper や OS の許可が再表示されない保証はありません。許可画面と GitHub から取得した DMG での起動は、すべての macOS 環境で未確認です。

macOS のセットアップウィザードから公式ページを開いた後、ページが前面に表示されない場合は、Dock からブラウザを選択してください。

#### OBS と NDI の初回準備

製品版の macOS 初回準備にも、OBS 用プラグインと NDI Runtime を利用者が公式 pkg から手動導入する方式を使います。macOS 用 DMG は現在、開発・検証用です。

検証環境（OBS Studio 32.2.2 / DistroAV 6.2.1 / NDI Runtime 6.3.2）では、OBS の初回起動時にカメラ機能拡張の有効化が必要でした。「システム設定」>「一般」>「ログイン項目と機能拡張」>「カメラ機能拡張」で OBS を有効にします（macOS のバージョンにより表示名や場所が異なる場合があります。macOS 27.0.1 の検証環境では、OBS の情報シートで「メディア機能拡張」と表示されました）。

NDI Runtime の pkg インストール時には Mac の管理者認証が、OBS の「DistroAV NDI Settings」を開いた際には NDI の送受信に使うローカルネットワークへのアクセス許可が求められました。確認が表示された場合は内容を読み、管理者認証やアクセス許可を本人が行ってください。

1. [DistroAV Releases](https://github.com/DistroAV/DistroAV/releases/latest) から最新の `distroav-*-macos-universal.pkg` を開いてインストールします。
2. [NDI Runtime for macOS](https://ndi.link/NDIRedistV6Apple) の pkg を開いてインストールします。
3. DistroAV と NDI Runtime のインストール後、OBS を終了して起動し直します。
4. OBS の「ツール」>「DistroAV NDI Settings」を開き、「Main Output」を有効にして「OK」を押し、設定を保存します。
5. Splat Replay のセットアップ画面に戻り、「NDI Runtime を再検査」を押します。DistroAV 6.2.1 は NDI Runtime 6.3 以降が必要です。バージョンを確認できない場合や 6.3 未満の場合、セットアップは完了になりません。

### OBS WebSocket の初回設定

OBS の「ツール」>「WebSocket サーバー設定」で WebSocket サーバーを有効にし、認証を有効にして表示されたパスワードを Splat Replay のセットアップへ入力します。OBS とアプリの接続ポート・パスワードを一致させてください。既定の WebSocket ポートは `4455` です。詳しくは [OBS のリモート操作ガイド](https://obsproject.com/kb/remote-control-guide) と [obs-websocket の接続案内](https://github.com/obsproject/obs-websocket#using-obs-websocket)を参照してください。

## 使い方

### 起動する

1. Switch をキャプチャーボード経由で PC に接続します。
2. Windows では `SplatReplay.exe`、macOS では「アプリケーション」の `SplatReplay.app` を起動します。
3. メイン画面のプレビューにゲーム映像が表示されることを確認します。

### 普段の流れ

- 起動後はゲーム映像を監視し、設定に応じて録画します。前回から残っている未処理動画は保持されますが、アプリ起動だけでは編集・アップロードを自動開始しません。
- 後処理はメイン画面の「処理開始」から手動で始めます。「電源オフ後に編集開始する」が有効な場合は、Switch の電源 OFF を検出した後に開始予告を表示し、その後に自動で始めます。
- 処理を始める前に XP・スペシャル回数・字幕などを確認して必要なら訂正してください。編集成果物が確定すると元録画が削除され、YouTube へのアップロード成功後は編集済み動画も削除されます。残しておきたい動画や必要なメタデータは、処理開始前にアプリ管理領域の外へ退避してください。
- 処理中に「処理後にスリープする」を切り替えた場合、その変更は今回の処理だけに適用され、設定として保存されません。通常の設定変更は「保存」から行います。
- YouTube 認証やアクセス許可が必要なときはブラウザが開くため、画面表示に従って認証を完了してください。
- 文字起こしを有効にしている場合は、録画中の音声も字幕用に扱います。

macOS では動画を `~/Library/Application Support/io.github.saw4405.splatreplay/videos`、設定を `config`、ログを `logs` に保存します。Google でログインしてアクセスを許可した後の YouTube 認証情報は Keychain に保存し、`client_secret.json` は `config` に置きます。Groq など他の API キーも Keychain に保存される、という意味ではありません。

録画は MKV で保持します。再生時にブラウザで扱える形式が必要な場合、一時 MP4 の準備に時間がかかることがあります。準備中は画面表示を待ち、再生できない場合は既存の再試行操作を使ってください。任意フォントがない場合は OS 標準フォントでサムネイルを生成します。

ローカル画面は OBS 仮想カメラに 1920×1080・60 FPS の映像取得を要求しますが、実際の値は機器によって異なります。LAN 端末ではカメラを使わず、静止画像を定期更新して表示するため、更新頻度はローカル画面より低くなります。OBS の元映像の画角や明るさは別に確認してください。黒画面や暗転は Switch 側の省電力表示が原因の場合もあります。

macOS アプリを更新する場合は、アプリを終了して新しい DMG 内の `SplatReplay.app` を「アプリケーション」へコピーし、既存アプリを置き換えてから DMG を取り出します。更新版も同じ署名主体を使いますが、macOS の許可が再表示されない保証はありません。

### 画面を閉じる・完全終了する

- ウィンドウを閉じると画面だけを隠し、映像の監視・録画・編集・アップロードは継続します。
- Windows は通知領域、macOS はメニューバーのアイコンで状態を確認できます。「画面を開く」で画面を再表示します。macOS は Dock のアイコンからも再表示できます。
- macOS はアプリアイコンの左下に小さな状態記号を重ねて表示します（○: 待機、●: 録画、⚙: 処理中、!: 要確認、…: 起動中）。詳しい状態はアイコンのツールチップとメニューで確認できます。
- アプリを停止する場合は、アイコンのメニューから「完全終了（処理完了を待つ）」を選びます。macOS のアプリメニューの終了や `Cmd+Q` も同じ動作です。
- 録画・編集・アップロードなどの保護対象の処理が終わってから終了します。処理が続いている場合は、終了まで時間がかかります。

### Windows: スマホやタブレットから開く

同じ家庭内 LAN に接続しているスマホやタブレットから、PC と同じ画面を開けます。
無認証で公開されるため、信頼できる家庭内ネットワークでだけ使ってください。

1. PC とスマホ、またはタブレットを同じ Wi-Fi に接続します。
2. Windows のネットワーク設定で、接続中の Wi-Fi を「プライベートネットワーク」にします。
3. Splat Replay の設定画面で「LAN 公開」を ON にして保存し、`SplatReplay.exe` を再起動します。
4. 再起動後、設定画面に表示された LAN 用 URL のポート番号を確認します。配布版の既定は `8000`、開発サーバーの既定は `5173` です。別のポートが表示された場合は、その番号を使います。
5. 管理者権限の PowerShell で Windows Firewall の受信許可を追加します。下の `8000` は例です。表示中の URL と同じポート番号に置き換えてください。

```powershell
New-NetFirewallRule `
  -DisplayName "Allow TCP 8000 Inbound from LocalSubnet" `
  -Direction Inbound `
  -Action Allow `
  -Protocol TCP `
  -LocalPort 8000 `
  -RemoteAddress LocalSubnet
```

6. 設定画面に表示された LAN 用 URL をスマホやタブレットのブラウザで開きます。Firewall に追加したポートが URL のポートと一致することを確認してください。

### macOS: スマホやタブレットから開く

1. Mac とスマホ、またはタブレットを同じ家庭内 LAN に接続します。
2. Splat Replay の設定画面で「LAN 公開」を ON にして保存し、アプリを再起動します。
3. 接続できない場合は、macOS の「システム設定」>「ネットワーク」>「ファイアウォール」で Splat Replay の受信接続を許可します。「プライバシーとセキュリティ」>「ローカルネットワーク」に Splat Replay が表示される場合は許可します。
4. 設定画面に表示される LAN 用 URL を、スマホやタブレットのブラウザで開いて接続を確認します。

LAN 公開は無認証です。信頼できる家庭内ネットワークでだけ使ってください。別端末からの接続は 2026-10-02 に確認済みです。

## 困ったとき

### セットアップウィザードが完了できない

- 起動時に必須設定の不足一覧が表示された場合は、各項目の「修復する」から該当カードを開いてください。外部ソフトの導入後や設定保存後に、画面の再確認操作を行います。
- 文字起こしを使わない場合は「使用しない」を保存してください。専用フォントがなくても OS 標準フォントでサムネイルを生成します。
- 外部ツールや認証情報の準備が必要な項目は、ウィザード内の案内に従ってください。
- macOS で Homebrew が必要な導入を行うと Terminal が開くことがあります。実行内容を本人が確認し、必要な認証を入力してください。初回導入では Xcode Command Line Tools もダウンロードされる場合があるため、処理が終わるまで Terminal を閉じずに待ってください。導入が終わったらウィザードでインストール状態を再確認します。[Homebrew の手順](https://docs.brew.sh/Installation)も参照できます。

### 録画やプレビューが始まらない

- Switch、キャプチャーボード、PC の接続を確認してください。
- OBS Studio と Splat Replay の両方で、ゲーム全体が正しい 16:9 の画角で表示されているか確認してください。左右の黒帯や横方向の縮みがないことも見ます。1920×1080 と表示されるだけでは画角が正しいとは限りません。
- READY は自動録画の待機状態です。マッチングを検出すると、画面にマッチング開始時刻が表示されます。この表示は OS の通知バナーとは別です。
- READY のままマッチングが検出されない場合は、OBS と Splat Replay の映像をもう一度確認してください。2026-10-03 は OBS でソースを選び直すと全面表示に戻り、その後マッチング検出とマッチング開始時刻表示が復帰しました。原因や必要な設定操作は未確認です。
- 映像が黒い・暗い場合は OBS の入力だけでなく Switch 側の省電力表示も確認してください。
- OBS 側で映像が出ているのに Splat Replay 側へ反映されない場合は、セットアップ時に確認した録画関連設定を見直してください。

### 音声の警告が表示される

- 音量メーター未反応などの表示は、OBS が観測した状態を示します。音声入力が完全に失われたと断定するものではありません。
- OBS の入力がミュートされていないか、選択した音声入力と録画トラックが正しいか、ゲーム音が入力されているかを確認してください。
- Switch の電源 ON 後は音声状態を観測し、初回確認待ちまたは音量メーター未反応の間はマッチング開始まで続けます。正常な音声を確認すると止まります。マッチングから待機に戻った場合は直前が音量メーター未反応のときだけ再開し、正常確認後は同じ電源周期で再開しません。次の電源 ON で新しい観測周期になります。無音を理由に OBS は再起動しません。

### YouTube 認証が求められる

- ブラウザが開いた場合は、画面の案内に従って認証とアクセス許可を完了してください。
- 認証に使う Google アカウントが、セットアップ時に想定した YouTube アカウントと同じか確認してください。
- Google OAuth のログインとアクセス許可、15分以上の動画で求められる YouTube 本人確認、macOS Keychain のアクセス許可は別の操作です。

### macOS Keychain の読み込みエラー

- 録画中は処理を中断せず、録画後に既存エラーを閉じてください。OSStatus `-128` のエラーが出た場合、録画済みまたは編集済み動画が一覧に残っていれば、既存の「処理開始」からもう一度実行します。
- macOS の Keychain 許可画面が実際に表示された場合は、内容を確認して本人が許可してください。誰が何をキャンセルしたか、また再試行で必ず復旧するかは未確認です。
- アップロード失敗を理由に残っている編集済み動画は削除されませんが、編集成功時点ですでに元録画が削除されている場合があります。必要な動画やメタデータは処理前に退避してください。

### 音声入力・文字起こしを確認する

- マイク名が一覧にあることは、実際に音声を取り込めている保証ではありません。送信機の電源・ペアリング、ミュート、マイク入力を確認してください。
- Groq API キーを保存しただけでは認証・文字起こしの成功を確認できません。設定画面の既存「音声認識テスト」を実行してください。API キーをチャットなどへ貼り付けないでください。
- macOS で FLAC が未導入の場合は、セットアップの案内に従って導入後、「インストール状態を再確認」を押します。
- macOS デスクトップ版の仮想カメラには macOS のカメラ権限と内蔵 WebView の許可が必要です。localhost をブラウザで開く場合は、そのブラウザの権限を確認してください。LAN 端末の画像 API 表示ではカメラ許可は不要です。拒否後に映像が出ない場合は該当するシステム設定またはブラウザ設定を本人が確認してください。拒否からの復旧は実機未確認です。[Apple のカメラ許可手順](https://support.apple.com/ja-jp/guide/mac-help/mchlf6d108da/mac)

### Switch の電源 OFF を検知できない

- キャプチャーボードによっては、Switch 電源 OFF 時の画面が異なります。
- 検知が安定しない場合は、電源 OFF 判定用画像の差し替えが必要になることがあります。

## カスタマイズ

### サムネイル画像を差し替える

自動生成サムネイルの上に重ねる画像を変更できます。

1. 1920x1080 の PNG 画像を用意します。
2. Windows では展開したフォルダの `assets/thumbnail/thumbnail_overlay.png` として保存します。macOS では `~/Library/Application Support/io.github.saw4405.splatreplay/assets/thumbnail/thumbnail_overlay.png` として保存します。必要なフォルダは先に作成してください。

macOS 版の `.app` 内は読み取り専用リソースです。変更する画像は Application Support に置いてください。

透過部分がある画像は、自動生成サムネイルの上に重ねて表示されます。
完全に不透明な画像を置いた場合は、自動生成部分が見えなくなります。
