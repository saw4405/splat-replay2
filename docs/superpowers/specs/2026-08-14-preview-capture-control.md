# プレビュー左上 Capture Control グレードアップ 実装契約

- 状態: 実装・検証完了
- 作成日: 2026-08-14
- 対象: メイン画面のゲームプレビュー左上にある録画状態表示・手動録画操作
- 関連仕様: `2026-08-13-switch-power-cycle-continuous-automation.md`

## 目的

内部の録画状態や Switch 電源状態をそのまま文字列で並べるのではなく、利用者が「今から遊んで自動録画されるか」「現在録画中か」「操作が必要か」をプレビュー上で直感的に判断できるようにする。

既存の左上表示が持つ手動録画の開始・一時停止・再開・停止機能は失わず、自動録画状態と矛盾して見えない一つの Capture Control として整理する。

## 目標

1. 左上の録画状態表示と、左下の Switch／自動録画状態表示を一つの Capture Control へ統合する。
2. 正常な定常状態はアイコンと短い状態語で静かに伝え、録画中・一時停止・未接続も同じ粒度の短い文字で揃える。
3. 状態表示と手動録画操作を同じ場所へまとめつつ、状態アイコン自体を録画開始・停止操作にはしない。
4. Switch 電源 OFF、キャプチャーデバイス未接続など、録画できない状態では無効な手動録画操作を表示しない。
5. 録画終了後に、実際の Switch／キャプチャー状態に応じた表示へ自動的に戻る。

## 方針

### 1. 利用者の次の行動を表示する

- `armed`: 次のバトルを録画できる状態として、シアンのゲームパッドアイコンと `READY` を表示する。
- `waiting_for_power_on`: Switch 電源 OFF として、低彩度の斜線付きゲームパッドを表示する。
- `recording`: 赤の録画点と `REC` を表示する。
- `paused`: オレンジの Pause アイコンと `PAUSE` を表示する。
- `capture_disconnected`: 明るいニュートラルグレーの Unplug アイコンと「未接続」を常時表示する。
- `unknown`／確認・復旧中: 確認中であることを spinner で示し、長引く場合だけ短い文字を表示する。

色だけには依存せず、アイコン形状と必要最小限の文字を組み合わせる。

### 2. 状態と操作を分離する

- 折りたたみ時は状態表示だけを見せる。
- hover、`focus-within`、タップによる展開時に、利用可能な手動録画操作を独立したボタンとして表示する。
- 状態アイコンは展開トリガーであり、録画開始・停止操作にはしない。
- `armed` では「手動録画を開始」を表示できる。
- `recording` では「一時停止」「停止」を表示する。
- `paused` では「再開」「停止」を表示する。
- `waiting_for_power_on`、`capture_disconnected`、確認・復旧中は録画操作を表示しない。

### 3. 表示優先順位を固定する

複数の内部状態が同時に観測される場合は、次の順で利用者向け表示を決める。

1. キャプチャーデバイス未接続・エラー
2. 録画一時停止
3. 録画中
4. 状態確認・復旧中
5. Switch 電源 OFF
6. バトル待受

録画停止後、Switch ON とキャプチャーデバイス接続が維持されていれば `armed` のゲームパッドへ戻る。Switch OFF を検出していれば斜線付きゲームパッド、デバイスが切断されていれば「未接続」を表示する。

### 4. 編集・アップロード表示と分離する

編集・アップロード進捗は録画状態とは別の表示軸とし、Capture Control の状態を上書きしない。進捗ダイアログがプレビューを覆う場合も、同じ状態を参照する小型表示により録画状態を確認できる構造を維持する。

### 5. アクセシビリティを維持する

- 状態はアクセシブル名と、意味のある状態遷移だけを通知する `aria-live` で伝える。
- 手動録画操作は `role="toolbar"` と明確な日本語のアクセシブル名を持つ独立ボタンにする。
- キーボードフォーカス中に操作部を閉じない。
- タッチ操作では状態トリガーのタップで開閉できるようにする。
- 無限アニメーションは使わず、`prefers-reduced-motion` を尊重する。

### 6. 手動操作を外枠内へ収める

- Capture Control は外寸 48px、状態トリガーと手動操作ボタンは 40px とし、ボタン外周に余白を確保する。
- 手動操作ボタン間と右内余白は 4px とし、1ボタン時は44px、2ボタン時は88px相当の内容適応幅にする。
- フォーカス表示はボタン内側へ描画し、丸い外枠の `overflow: hidden` を維持する。
- 親要素の overflow を解除して枠外描画を許す方法や、操作領域を縮小する方法は採用しない。

## 対象範囲

- `VideoPreview.svelte` の録画状態表示と手動録画操作。
- `VideoPreviewContainer.svelte` の Switch／自動録画状態表示との統合。
- 既存の RecorderState と SwitchPowerState から利用者向け表示を決めるフロントエンドロジック。
- プレビュー左下の常設電源状態 pill の撤去。
- hover、focus、タップ、キーボード操作を含む Capture Control の表示・操作。
- 対応する frontend component／integration テストと必要な静的検証。

- 進捗ダイアログ全体の再設計。
- プレビュー以外の画面にある状態表示の一括変更。
- アイコンライブラリの置換。
- デザインテーマ全体の色トークン再設計。
