# 進捗ダイアログ 900×720タイムライン同時表示 設計追補

## 目的

縦型レイアウトの900×720において、現在処理中の動画プレビューとタイムライン1段を、進捗本文のスクロール位置0で同時に確認できるようにする。

## 決定

- 641～900pxでは、編集中パネルの高さを利用可能な画面高に収める。
- 編集モニターを「メタデータ / 可変高プレビュー / 現在タイムライン」の3行グリッドにする。
- プレビューは16:9を維持し、利用可能な高さに合わせて中央で縮小する。
- 900px以下では、現在処理中ではないタイムライン行を非表示にする。
- タイムラインの進捗、再生ヘッド、クリップ情報は省略しない。
- 901px以上の3列レイアウトと、640px以下のスマートフォン向け本文スクロールは維持する。

## 受入基準

1. 900×720でプレビューと現在タイムライン1段が、本文をスクロールせず同時に見える。
2. プレビューは16:9を維持する。
3. 後続のタイムライン行は縦型レイアウトで表示領域を消費しない。
4. 901×720の既存3列レイアウトを変更しない。
5. 320×568では既存の本文スクロールとフッター到達性を維持する。

## テスト方針

- 参照方針: `docs/test_strategy.md`
- 変更分類: workflow + static
- 新規テスト判断: 既存の900px境界E2Eを更新し、表示領域内への収容をユーザー可視要素の位置で検証する。
- componentテストは意味契約や状態分岐を変更しないため追加しない。
- integration / contract / performanceは対象境界を変更しないため不要とする。
