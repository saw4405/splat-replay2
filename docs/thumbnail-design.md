# サムネイルデザイン

「設定」→「すべての設定」→「編集」→「サムネイルデザインを編集」から開きます。

## 編集と保存

- 名前を伏せた実際のリザルト画面と、その画面からの高キルレ切り抜きを使用します。集計値は表示確認用です。「表示を確認」からXマッチ、イベント、レートなし、バンカラ、1試合を切り替えられます。
- 左をプレビューと背景の設定帯、右を要素一覧とプロパティの編集レールとしています。カードごとの枠・見出し帯を使わず、配置と余白で操作を区別します。表示パターンと表示倍率はプレビュー内、取り消し／やり直しはヘッダーにあります。
- 要素一覧と編集内容は独立してスクロールします。文字を追加すると、編集パネル最上部の「文字内容」にフォーカスします。キャンバスの文字をダブルクリックしても入力へ戻れます。通常の要素選択ではフォーカスを奪いません。
- 選択枠は白黒の二重線で表示します。位置のドラッグ対象を示すもので、拡縮ハンドルではありません。
- 通常モードでは、プレビュー内の画像の空白・画像外の作業面をクリックすると選択を解除します。背景移動・スポイト・表示パターンの変更は解除と競合させません。
- 要素名と不透明度は折りたたまず表示します。使える変数は文字入力欄直下でヒントを展開し、波括弧込みでコピーできます。コピー結果を表示し、失敗した場合は手動コピー用の文字列を選択します。
- レイヤーは手前の要素を上に表示します。レイヤー一覧で表示を切り替え、プレビューでドラッグするか、属性欄のX・Yで位置を調整します。矢印キーでも移動できます。Shift併用で10px移動します。
- 文字・図形・画像を追加・削除できます。フォント・文字サイズ・色・縁取り、図形の種類・サイズ・透明度、画像サイズ、重なり順を編集できます。スポイトはプレビュー内の色を取得します。
- ステージ画像と高キルレの切り抜きは、それぞれ一つのまとまりとして移動・サイズ変更します。抽出条件と並びは従来どおりです。
- 「背景の設定」で「リザルト画面」／「画像ファイル」を選びます。アップロードも同じパネルから行います。どちらも「背景を移動」でプレビュー内をドラッグできます。Escまたは同じボタンで移動を終了します。移動中は要素を選択しません。
- 背景の横位置・縦位置と「背景の倍率」を同じパネルで調整できます。100%は縦横比を保って全面を埋めるサイズで、400%まで拡大できます。「位置・倍率を戻す」は中央・100%に戻し、背景素材は保持します。「表示倍率」は編集画面の表示だけを変えます。
- 「適用」で実際の生成処理によるサンプルを確認します。「編集に戻る」で修正でき、「このデザインを使う」で親の設定へ戻ります。親の「保存」で初めて確定します。
- 自動プレビュー更新中も「適用」を押せます。適用時の生成を優先し、遅れて返る自動更新で確認画面を上書きしません。
- 親でキャンセルすると、採用したデザイン変更も破棄します。保存後に開始するサムネイル生成へ適用し、生成済み画像は変更しません。

## 素材

PNG・JPEG・WebPの20MB以下・2000万画素以下の画像をアップロードできます。
アップロード素材は `assets/thumbnail/uploads/` にPNGとして保存します。
macOS配布版ではユーザーデータ領域の `assets/thumbnail/` を使います。

素材追加・削除は即時反映され、設定のキャンセルでは戻りません。
同梱素材、保存済みデザイン・編集中デザイン・生成中の画像から参照されている素材は削除できません。
参照を外して設定を保存してから削除してください。

## 設定形式とテンプレート

初期デザインの正本は `backend/assets/thumbnail/design.default.json` です。
編集したデザインは、既存の `config/settings.toml` の `video_edit.thumbnail_design` に構造化して保存します。
初期デザインだけを使う既存設定ファイルは、読み込みだけでは書き換えません。次の設定保存時にデザインを出力します。

デザインは版番号、背景、描画順の要素配列で構成します。文字は展開後の値でなく、テンプレートを保存します。
未知の変数・要素・版、不正な色・座標・サイズ、重複する要素ID、失われた素材参照は拒否します。

| 変数 | 内容 |
| --- | --- |
| `{WIN}` / `{LOSE}` | 勝数・敗数 |
| `{RATE}` | ラベル付きのサムネイル用レート表記 |
| `{RATE_LABEL}` | `XP: `、`Best Power: `などのラベル。ラベルなしのマッチでは空文字 |
| `{RATE_VALUE}` | レート値、または最小値～最大値 |
| `{RATE_MIN}` / `{RATE_MAX}` | 最小・最大のレート値 |
| `{BATTLE}` / `{RULE}` / `{STAGES}` | マッチ・ルール・ステージ名 |

初期の勝敗は `{WIN} - {LOSE}`、レートは `{RATE_LABEL}{RATE_VALUE}` です。
動画タイトルと同じ波括弧の構文ですが、レートは短縮しません。
`{WIN:02d}` などの単純な書式指定と、`{{`・`}}` による波括弧のエスケープを使用できます。
レート情報がない場合、専用のレート要素は非表示にします。追加文字では欠けた情報を空文字にし、残りを表示します。

## 検証の境界

参照方針は `docs/test_strategy.md` です。分類は static / logic / component / integration / contract / workflow です。
新規分岐であるテンプレート検証、描画要素、素材の参照保護・入出力、子と親の保存境界をテスト対象とします。
プレビュー画像とクリック・ドラッグの矩形は同じ描画結果から返し、文字の字形・縁取りを含む実測範囲を使います。描画されなかった要素はクリック対象にしません。
初期レイアウトは旧実装で生成した5種類の固定PNGと比較します。比較元の出自は `backend/tests/fixtures/thumbnail_design/README.md` に記載しています。

対象テストと静的検証を選び、全体verify・release・性能テストは実施対象にしていません。
この変更はOCRや録画判定の時間予算を変更しません。配布物の再ビルド、Windows実機・macOSアプリでの受け入れは別途確認が必要です。

2026-10-27のローカル検証結果:

- 保証対象: 実描画による選択枠、実画像の切り抜き、初期デザインの画素再現、テンプレート・入力検証、素材の保存と削除保護、背景・透明度描画、親子ダイアログの確定・取消。
- 新規テスト: logic / contract / component / integration / workflow に追加。既存のサムネイル、設定、AutoEditor、持込動画renderer、編集済み動画一覧の対象テストも確認。
- 実行入口: `scripts/run-backend-pytest.py` に対象ファイルを指定、`npm run test:component -- <対象>`、`npm run test:integration -- <対象>`、`npm run test:e2e -- <対象>`。
- 静的検証: Ruff、ty、import-lint、TypeScript、svelte-check、ESLint、変更ファイルの書式確認。型・Svelteの警告も解消。
- 画像比較: 固定比較元5種類で全画素一致。実リザルト画像の新サンプルも、変更前の生成コードと新コードを同じ入力で比較し、5種類すべて全画素一致。
- ブラウザ導線: 既存アプリと分離した検証用ポート・設定ファイル・既存Chromeの一時プロファイルで、D&D、図形、スポイト、実生成確認、保存、再読込、親の取消を確認。
- 省略: 全体verify・workflow全件・release・性能gateは、今回の保証を対象別の入口で確認できるため実行しない。
- 未確認・追加確認: Windows実機と配布macOSアプリの操作。配布物を更新する際は、再ビルド後にフォント・素材・画像選択・保存導線を対象OSで確認する。
