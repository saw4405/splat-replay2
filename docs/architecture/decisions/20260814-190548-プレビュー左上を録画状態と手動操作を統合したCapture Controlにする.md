# プレビュー左上を録画状態と手動操作を統合したCapture Controlにする

- ID: 20260814-190548
- 状態: accepted
- 日時: 2026-08-14T19:05:48+09:00
- 判断者: 共同

## 目的・問題

プレビューには、左上の実録画状態と手動録画操作、左下の Switch・自動録画状態が別々に存在し、正常なバトル待受でも `Stopped` と「バトル待受中」が同時に見える可能性がある。利用者が「今から遊んで録画できるか」「現在録画中か」「手動操作できるか」を一箇所で判断できるようにしつつ、既存の手動録画機能を失わない表示へ統合する。

また、録画できない Switch 電源 OFF・キャプチャーデバイス未接続では無効な手動操作を見せず、編集・アップロードの進捗によって現在の録画可否が隠れないようにする。

## 前提・制約

- 左上の現行表示は状態表示だけでなく、手動録画の開始・一時停止・再開・停止を担っている。この機能を維持する。
- `waiting_for_power_on` は Switch 電源 OFF を検知して ON を待つ、ゲームプレイおよび録画ができない状態として扱う。
- `capture_disconnected` はキャプチャーデバイスが未接続で、録画操作ができない状態として扱う。
- 自動録画、Switch 電源監視、キャプチャーデバイス切断判定、編集・アップロードのバックエンドライフサイクルは変更しない。
- 色だけで状態を区別せず、アイコン形状と必要最小限の文字を併用する。
- 既存の手動録画 API の契約は変更しない。

## 判断

1. プレビュー左上を、自動録画・Switch・キャプチャー状態と既存の手動録画操作を統合した一つの `Capture Control` とする。
2. 折りたたみ時は状態を表示し、hover、キーボード focus、tap で展開したときだけ、その状態で利用可能な手動操作を独立したボタンとして表示する。状態アイコン自体は録画開始・一時停止・再開・停止を実行しない。
3. 状態と操作を次のように対応させる。

| 状態 | 折りたたみ時の表示 | 展開時の手動操作 |
| --- | --- | --- |
| `armed`（バトル待受） | シアンのゲームパッド単体 | 手動録画開始 |
| `waiting_for_power_on` | 低彩度の斜線付きゲームパッド | なし |
| `recording` | 赤の録画点と `REC` | 一時停止、停止 |
| `paused` | オレンジの Pause アイコンと「一時停止」 | 再開、停止 |
| `capture_disconnected` | 明るいニュートラルグレーの Unplug アイコンと常時「未接続」 | なし |

4. 録画終了後は固定の停止表示へ遷移させず、その時点の Switch・キャプチャー状態を再び表示する。Switch ON かつ接続維持なら `armed` のゲームパッド、Switch OFF なら斜線付きゲームパッド、切断なら「未接続」とする。
5. 編集・アップロード進捗は録画状態と別 lane に置き、進捗状態で `Capture Control` の録画状態を上書きしない。

## 検討した選択肢と棄却理由

### 左上を状態表示だけのキャプチャービーコンへ置き換える

初期提案。表示は単純になるが、左上が持つ既存の手動録画制御を失う。ユーザーの指摘を受け、状態と手動操作を一つの場所へ統合しながら、独立ボタンで操作する `Capture Control` へ修正した。

### 左上の実録画状態と左下の自動録画・電源状態を分けたままにする

実録画の `Stopped` と自動録画のバトル待受が同時に見え、利用者には停止中なのか録画準備済みなのかが矛盾して見えるため棄却した。

### 状態アイコン自体を録画操作にする

状態確認または展開のつもりの操作が、録画開始・停止へ直結して誤操作になり得る。状態の確認と録画操作を区別するため、操作は展開後の独立ボタンに限定した。

### Switch電源OFF・未接続でも手動録画ボタンを表示する

ゲームプレイおよび録画ができない状態で実行不能な操作を提示することになるため棄却した。

### バトル待受をチェック付きまたは準備完了専用アイコンにする

ゲームパッド＋チェック、`CircleCheck` を含む準備完了表現を検討した。ユーザーは最終的に「ゲームアイコンのみ」を選択したため、シアンのゲームパッド単体とした。

### 未接続を一時停止と同じオレンジで表示する

一時停止の意味色と競合し、異なる状態の見分けを弱める。Unplug の形状と「未接続」の文字で意味を伝え、色は明るいニュートラルグレーへ分離した。

### 編集・アップロード進捗で録画状態を置き換える

編集・アップロード中にも録画機能が並行して動作するため、進捗で録画状態を上書きすると現在の録画可否が分からなくなる。別 lane として併存させる。

## 適用範囲

- メイン画面のゲームプレビュー左上にある録画状態表示。
- 自動録画・Switch・キャプチャー状態から利用者向け状態を選ぶフロントエンド表示。
- 左上で提供する既存の手動録画開始・一時停止・再開・停止の見せ方と操作可否。
- hover、focus、tap による操作部の展開。
- 録画終了後の表示復帰。
- 編集・アップロード進捗と録画状態の表示境界。

## 適用しない範囲

- 自動録画、Switch 電源監視、キャプチャーデバイス切断判定の状態遷移や精度。
- 録画開始・一時停止・再開・停止 API の仕様。
- 編集・アップロード処理の実行方式や進捗ダイアログ全体の再設計。
- プレビュー以外の画面にある状態表示。
- アイコンライブラリ、テーマ全体の色トークン、バックエンド状態名の変更。

## 期待する効果

- 正常なバトル待受を停止状態と誤認せず、今からゲームを開始して録画できることを一目で判断できる。
- 既存の手動録画機能を維持しながら、状態確認と録画操作の誤クリックを防げる。
- ゲームプレイできない状態では無効な録画操作を見せず、必要な状態だけを端的に伝えられる。
- 一時停止と未接続を色・形・文字で区別できる。
- 録画終了後や編集・アップロード中にも、実際の録画可否を継続して確認できる。

## 受け入れる欠点・リスク

- 折りたたみ時に手動操作が見えないため、初回利用者が展開可能だと気づきにくい可能性がある。
- hover のないタッチ環境とキーボード環境で同等に展開・フォーカス維持できる実装が必要になる。
- RecorderState と SwitchPowerState が同時に変化する境界では、表示優先順位や更新順によって短時間の中間表示が見える可能性がある。
- `armed` をゲームパッド単体にしたため、「準備完了」という意味は専用チェックより抽象的である。この簡潔さはユーザーが明示的に選択した。
- Switch OFF 検知が確定するまでは、録画終了後に一時的に `armed` 表示が残る可能性がある。判定精度や確定時間は本 ADR の対象外である。

## 再検討条件

- 利用者が状態表示を手動録画ボタンと誤認する、または展開方法を発見できない場合。
- タッチまたはキーボード操作で、手動録画制御へ安定して到達できない場合。
- 新しい録画不能状態、復旧操作、エラー状態を `Capture Control` に追加する場合。
- `armed` のゲームパッド単体では準備完了の意味が伝わらないことが利用確認で判明した場合。
- 編集・アップロード進捗と録画状態を同じ領域で同時表示できない画面構造へ変更する場合。
- バックエンドの録画・電源状態モデルまたは手動録画 API が変更された場合。

## ユーザー発言の原文

左上の既存責務を指摘した原文:

> 左上の録画表示は、手動での録画制御の機能もあります

この指摘を受けて修正したメインエージェントの提案:

> おっしゃるとおりです。左上は廃止せず、状態アイコンを開くと既存の「開始・一時停止・再開・停止」が現れる統合コントロールへ修正しました。状態アイコン自体は録画操作にせず、各操作ボタンを分離しています。
>
> 左上の表示をクリックまたはホバーしてご確認ください。

Switch 電源 OFF、手動操作、待受アイコン、未接続表記を指定した原文:

> Switch待機って電源オフってこと？
> であれば、ゲームアイコンに斜線をひくか、何かで電源が入ってないことが伝わればいい。ゲームプレイできない状態だから、手動録画ボタンも不要。
>
> バトル待受のアイコンが分かりづらい。現行のアイコンは何だっけ？
>
> 接続を確認じゃなくて、未接続と表示させて

録画終了後と編集・アップロード中の表示を説明したメインエージェントの提案:

> 録画終了後は次の状態になります。
>
> - Switch ON・接続中：準備完了アイコンへ戻る
> - Switch OFF検知後：斜線付きゲームパッド
> - キャプチャーデバイス切断：`未接続`
> - 編集・アップロード中：上記の録画状態をそのまま維持

バトル待受、一時停止、未接続の最終表現を指定した原文:

> バトル待受は、ゲームアイコンのみでいい
> 録画を一時停止中はオレンジ色です。未接続の色を変えてください。

上記指定を反映したメインエージェントの提案:

> 反映しました。
>
> - バトル待受：シアンのゲームパッドのみ
> - 一時停止：オレンジ
> - 未接続：明るいニュートラルグレー＋「未接続」
> - Switch OFF：より低彩度の斜線付きゲームパッド

累積した提案を実装対象として受諾した原文:

> いいね、プレビュー画面左上の録画状態表示をグレードアップ実装してください。
