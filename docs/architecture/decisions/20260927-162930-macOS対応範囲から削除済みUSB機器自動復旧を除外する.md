# macOS 対応範囲から削除済み USB 機器自動復旧を除外する

- ID: 20260927-162930
- 状態: accepted
- 日時: 2026-09-27T16:29:30+09:00
- 判断者: ユーザー

## 目的・問題

macOS の初回対応は全機能同等を目標としていた。M4 の調査対象に機器列挙・切断検知とともに USB 復旧が含まれたが、その機能は最新 `main` で削除済みであり、macOS に同機能を追加する必要はないとユーザーが明示した。macOS の対応範囲を、現在の製品機能に合わせて確定する。

## 前提・制約

- 先行するユーザー判断は「全機能を同等に対応」「Apple Silicon のみ」である。
- 対象会話では、M4 の調査対象として機器の列挙・切断検知・USB 復旧が挙げられていた。
- 記録時の `HEAD` は `57e1cd1`（`fix: restore capture device status without recovery`）である。同コミットではキャプチャ機器の復旧サービス/API と実装が削除され、機器状態の取得が残されている。
- USB 機器自動復旧を除外する判断はユーザーが明示した。手動復旧の方法は未確認であり、本判断では定めない。

## 判断

1. macOS の機能同等性は、現在の `main` に存在する機能を基準とする。
2. 削除済みの USB 機器自動復旧を macOS 対応へ追加しない。
3. この例外は USB 機器自動復旧に限る。Apple Silicon を対象とする方針と、現在の `main` に残る機能を同等に対応する方針は維持する。

## 検討した選択肢と棄却理由

### 先行する「全機能同等」の文言を理由に USB 機器自動復旧も macOS に実装する

ユーザーが機能削除を理由に「実装不要」と明示したため採用しない。会話でほかの実装案や比較理由は提示されていない。

## 適用範囲

- Apple Silicon 向け macOS 初回対応の機能範囲。
- キャプチャ機器の列挙・接続判定・切断監視を含む M4 のうち、USB 機器の自動復旧を行わない判断。
- 全機能同等の基準を現行 `main` の機能集合へ合わせること。

## 適用しない範囲

- `main` に残る機能の macOS 対応範囲や方式の変更。
- USB 機器の手動復旧手順。
- OBS 音声の自動復旧。これは USB 機器自動復旧とは異なる機能であり、関連する既存 ADR の判断を変更しない。
- Intel Mac、他 OS の対応範囲。

## 期待する効果

- `main` から削除された機能を、macOS 対応のために再導入することを避けられる。
- macOS の「全機能同等」が、過去に存在した削除済み機能まで含むという誤解を防げる。

## 受け入れる欠点・リスク

- macOS 版は USB 機器の自動復旧を行わない。手動復旧の方法と利用者への案内は本判断では未確定である。
- 将来 `main` に USB 機器自動復旧が再導入された場合、macOS でも同等にするかは改めて判断が必要となる。

## 再検討条件

- USB 機器自動復旧が `main` に再導入された場合。
- ユーザーが macOS の対応範囲を改めて定め、USB 機器自動復旧を含めると明示した場合。

## 関連する設計指針

登録済みの設計指針はない。本判断は macOS 対応における個別の機能範囲であり、一般化した設計指針を新設しない。
