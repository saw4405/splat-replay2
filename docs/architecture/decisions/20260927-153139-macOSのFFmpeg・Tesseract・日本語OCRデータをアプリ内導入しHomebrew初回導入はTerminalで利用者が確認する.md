# macOS の FFmpeg・Tesseract・日本語 OCR データをアプリ内導入し、Homebrew 初回導入は Terminal で利用者が確認する

- ID: 20260927-153139
- 状態: accepted
- 日時: 2026-09-27T15:31:39+09:00
- 判断者: ユーザー

## 目的・問題

macOS で全機能を同等に提供する方針に沿い、FFmpeg、Tesseract、日本語 OCR データの初回準備をアプリから行えるようにします。macOS の依存導入を利用者任せにするか、アプリ内のセットアップで扱うかを決める必要がありました。

## 前提・制約

- macOS 対応の範囲は全機能同等、対象 CPU は Apple Silicon のみです。
- ユーザーは、macOS でアプリが正常動作することを目標とし、利用者への影響が大きい判断は確認するよう求めました。
- 会話中の調査報告では、既存の FFmpeg・Tesseract 導入 API は `C:` パスと PowerShell に依存するとされ、macOS 画面からその処理を直接呼ばない安全策が先行しました。この記述は親トランスクリプト上の報告であり、本 ADR 作成時のコード再調査ではありません。
- Homebrew の初回導入では、公式インストーラーを開いた Terminal 上で利用者の確認・入力が必要になる場合があります。管理者入力の要否は環境によります。
- Homebrew の具体的なパッケージ名・版、日本語 OCR データの配布単位、更新方針、導入完了の検査方法は、この判断では確定していません。

## 判断

1. macOS のセットアップ画面から、Homebrew を使って FFmpeg、Tesseract、日本語 OCR データを導入します。
2. Homebrew がない場合も、アプリの導入ボタンから Homebrew の公式インストーラーを Terminal で開きます。公式インストーラーの確認と、必要な管理者入力は利用者が行います。
3. 本判断の対象は Apple Silicon 搭載 Mac の初回セットアップです。Intel Mac、他 OS、既存導入後の更新方針は決めません。

## 検討した選択肢と棄却理由

### 公式配布元を案内し、利用者が FFmpeg・Tesseract を入れてからアプリが再検査する

初回導入の選択肢として質問されましたが、ユーザーは macOS でもアプリ内自動導入を必須としました。このため、依存を利用者が別途導入する方式は採用しません。

### Homebrew が既にあることを前提に、アプリから FFmpeg・Tesseract・日本語 OCR データを入れる

最初の Homebrew 案は、Homebrew 自体は利用者が先に公式手順で導入する前提でした。ユーザーは Homebrew 自体もアプリから導入するよう指定したため、この前提では採用しません。

### Homebrew の初回導入を Terminal から利用者が確認・入力する

アプリの導入ボタンで Terminal を開き、公式インストーラーの確認と必要な入力を利用者が行う案をユーザーが選択しました。Homebrew の初回導入はこの方式とします。

## 適用範囲

- Apple Silicon 搭載 Mac のアプリ内セットアップ。
- Homebrew、FFmpeg、Tesseract、日本語 OCR データの初回導入導線。
- Homebrew の公式インストーラーをアプリの導入ボタンから Terminal で開始し、利用者が確認・必要な入力を行う導線。

## 適用しない範囲

- Intel Mac、Windows、Linux。
- 既に導入済みの Homebrew、FFmpeg、Tesseract、日本語 OCR データの更新・削除方針。
- Homebrew の具体的な formula 名・版、日本語 OCR データの配布方法、完了判定の具体的な契約。
- 実機でのインストーラー成功、署名・配布保証、OCR の認識精度。

## 期待する効果

- macOS の全機能同等方針に必要な FFmpeg・Tesseract・日本語 OCR データを、アプリのセットアップ導線から用意できます。
- Homebrew がない場合も、利用者が自分でアプリ外の手順を探すことなく、アプリから初回導入を開始できます。
- Homebrew の確認と必要な管理者入力を利用者が行うことを導入フロー上で明確にできます。

## 受け入れる欠点・リスク

- Homebrew の初回導入では Terminal の確認や、環境に応じて管理者入力が必要です。
- 導入フローは Homebrew の公式インストーラーと Homebrew で提供する対象パッケージに依存します。Apple Silicon 上での具体的なパッケージ可用性は本記録では検証していません。
- 会話中の実装報告では、Finder から起動した `.app` で Homebrew のコマンドパスを検出できない場合があるとされました。検出・実行方法は実装上の確認事項であり、この ADR では具体化しません。
- 本 ADR は導入方針の決定を記録するもので、実機上で公式インストーラーが完了することや各機能が動くことの検証結果を示すものではありません。

## 再検討条件

- Homebrew の公式インストーラーをアプリから Terminal で開始する導線が利用できなくなったとき。
- Apple Silicon 上で Homebrew 経由の FFmpeg、Tesseract、日本語 OCR データを提供できないことが確認されたとき。
- macOS 対応範囲を Intel Mac へ広げる、または依存更新の責務を定める必要が生じたとき。

## ユーザー発言の原文

### macOS 対応の目的

> このアプリがmacでも正常動作することを目標として取り組んでください。
> まずは対応が必要な機能を一覧化してください。
> 次に対応方針を整理し、サブエージェント(astra・軽)にアドバイスをもらってください。
> そしたら、どの順番で取り掛かるかまでをファイルに永続化して私に報告してください。
>
> ユーザー影響や影響が大きい判断が必要な時は私に聞いてください。

### macOS の対応範囲

先行する質問（assistant）:

> 対象を確定するため、**Apple Silicon のみか Intel Mac も含むか**、**初回から全機能を同等にするか主要導線を先行するか**の回答をお願いします。

回答（user）:

> 全機能を同等に対応
> Apple Silicon のみ

回答（user）:

> macOS でもアプリ内自動導入を必須にする

### Homebrew と日本語 OCR データ

質問（assistant）:

> macOS のアプリ内自動導入は Homebrew を前提にし、アプリのボタンから FFmpeg・Tesseract・日本語OCRデータを導入する方式で進めてよいですか？ Homebrew 自体がない場合は利用者が先に公式手順で導入します。

回答（user）:

> Homebrew 自体もアプリから導入する

### Homebrew 初回導入時の Terminal 操作

質問（assistant）:

> Homebrew の初回導入では管理者パスワード入力が必要になる場合があります。アプリの「導入」ボタンで Terminal を開き、公式インストーラーの確認・入力を利用者が行う方式でよいですか？

回答（user）:

> Terminal で確認・入力する（推奨）
