# Apple Silicon の Google 音声認識向け FLAC をアプリ内 Homebrew で導入する

- ID: 20260927-205826
- 状態: accepted
- 日時: 2026-09-27T20:58:26+09:00
- 判断者: ユーザー

## 目的・問題

Apple Silicon の macOS アプリで Google 音声認識と字幕生成を使えるよう、音声を FLAC に変換する実行ファイルの供給方式を決めます。親トランスクリプト内の調査報告では、同梱されている `flac-mac` が x86_64 のため Apple Silicon 上で `bad CPU type in executable` となり、Google 認識を含む字幕導線を阻害していました。

## 前提・制約

- 親トランスクリプト内の助言報告では、SpeechRecognition は PATH 上の `flac` を優先し、見つからない場合に同梱 `flac-mac` を使うとされています。本 RECORD ではコードを再調査していません。
- 同じ報告では、Google と Groq の認識が統合され、Google 側の FLAC 実行失敗が両方の結果に波及するとされています。この実動作は本 RECORD では再検証していません。
- Apple Silicon 向けの実行可能な FLAC encoder が必要です。具体的な Homebrew formula 名・版は未確認です。
- 既存の Homebrew 初回導入方式は、別 ADR で公式インストーラーを Terminal から開始し、利用者が確認・必要な入力を行う方式として決定済みです。

## 判断

1. Google 音声認識に必要な FLAC encoder を、既存のアプリ内 Homebrew 導入対象に追加します。
2. arm64 の FLAC 実行ファイルを `.app` に同梱する方式は採用しません。利用者はアプリ内 Homebrew 方式を選択しました。
3. この判断は Apple Silicon 搭載 Mac のアプリ内セットアップに適用し、音声認識方式や Homebrew 初回導入手順は変更しません。

## 検討した選択肢と棄却理由

### アプリ内 Homebrew で FLAC を導入する

ユーザーが選択した方式です。助言報告では、既存の PATH 解決とアプリ内 Homebrew 導入を利用でき、配布バイナリを個別に管理する変更を抑えられるとされました。Homebrew 未導入・導入失敗・後から削除された場合の検出と案内は未確定です。

### arm64 FLAC 実行ファイルを `.app` に同梱する

追加導入を避けられますが、質問文で署名・更新・ライセンス管理の負担が増えると示されました。ユーザーは Homebrew 方式を選んだため採用しません。助言報告では、同梱バイナリに外部 dylib 依存が残る可能性も挙げられていますが、本 RECORD では確認していません。

### Python ライブラリで FLAC を生成する

助言役が代替案として挙げました。追加依存や SpeechRecognition との接続変更が必要になり得て、arm64 の frozen アプリで成立するか未確認と報告されました。ユーザーに提示した最終選択肢ではなく、採用しません。

### Google 認識を外し、Groq のみを使う

助言役の報告では、全機能同等の方針や現在の統合認識動作を変更するため今回の候補外とされました。この ADR は認識方式を変更しません。

## 適用範囲

- Apple Silicon 搭載 Mac のアプリ内セットアップ。
- Google 音声認識が利用する FLAC encoder の供給方式。
- 既存のアプリ内 Homebrew 導入導線への FLAC の追加。

## 適用しない範囲

- Intel Mac、Windows、Linux。
- Homebrew formula 名・版、導入タイミング、更新・削除方針。
- 導入失敗や encoder 不在時の具体的な再検査・表示契約。
- `.app` の署名・公証、配布、実機での音声認識・字幕生成の保証。
- Google または Groq の認識方式・統合動作の変更。

## 期待する効果

- Apple Silicon 上で Google 音声認識に必要な arm64 対応 FLAC encoder を、アプリ内セットアップから導入できるようにします。
- 既知の x86_64 同梱 `flac-mac` への fallback に依存しない導入方針を定めます。

## 受け入れる欠点・リスク

- FLAC の利用に Homebrew とその導入対象パッケージが必要です。
- Homebrew が未導入の場合は、既存 ADR に定めた Terminal 上での利用者確認・必要な入力を伴います。
- Homebrew または FLAC の導入失敗、外部削除、PATH 解決失敗に対する検出・案内方法は未確定です。
- 本 ADR は供給方式の判断を記録するもので、導入の成功や実機での字幕生成を確認した記録ではありません。

## 再検討条件

- アプリ内 Homebrew から Apple Silicon 対応の FLAC encoder を導入できないことが確認されたとき。
- Homebrew 依存が macOS の導入・配布要件に合わないことが分かったとき。
- FLAC の具体的なパッケージ、更新・削除、失敗時の扱いを確定する必要が生じたとき。
