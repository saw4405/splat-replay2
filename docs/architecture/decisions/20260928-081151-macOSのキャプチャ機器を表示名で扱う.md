# macOSのキャプチャ機器を表示名で扱う

- ID: 20260928-081151
- 状態: accepted
- 日時: 2026-09-28T08:11:51+09:00
- 判断者: ユーザー

## 目的・問題


## 前提・制約

- 先行するユーザー判断は、macOS で「全機能を同等に対応」、対象を「Apple Silicon のみ」とするものです。
- 会話中の Windows 版に関する調査・質問では、キャプチャ機器設定は表示名を保存すると報告されています。同じ表示名だけを保存する方式から、同名の複数機器を個別に選択・永続識別できないことは導けます。実際の macOS 機器列挙と接続判定は、この ADR 作成時点で未確認です。
- 同名機器が複数ある場合の一覧表示・接続判定の細かな挙動は、ユーザー発言では指定されていません。

## 判断

1. macOS のキャプチャ機器設定は、既存 Windows 版と同じ表示名保存方式を維持します。機器ごとの一意 ID を設定値として保存する方式へは変更しません。
2. 表示名が同じ機器を個別に選択・識別できない制約を受け入れます。この判断は、同名時の接続判定や UI の詳細な振る舞いまでは定めません。

## 検討した選択肢と棄却理由

### 同名機器を個別に選ぶため識別子を保存する

会話では同名機器の個別選択が推奨案として提示されました。ユーザーは同名機器があっても現在の方式で続けてよいと回答し、直後の assistant も既存の表示名方式を維持すると確認しました。個別識別案を採用しない理由の詳細は、ユーザーから明示されていません。

### Windows 版と同じ表示名を保存する

既存方式を維持する選択肢です。ユーザーの回答を受け、本 ADR の判断として採用します。同名機器が個別に区別できない制約を伴います。

## 適用範囲

- macOS 版のキャプチャ機器設定における保存値の識別単位。
- Windows 版と共通する表示名保存方式を macOS でも維持する判断。

## 適用しない範囲

- 同名機器が列挙された場合の表示、選択 UI、接続判定の詳細。
- macOS 上の実機キャプチャ・権限・切断監視の動作保証。
- USB 機器の自動復旧。これは既存 ADR `20260927-162930` の判断対象であり、本 ADR は変更しません。

## 期待する効果

- macOS 用にキャプチャ機器設定の識別方式を変更せず、Windows 版と表示名保存の契約を揃えられます。

## 受け入れる欠点・リスク

- 同名機器は保存値から個体を区別できません。誤った機器を選ばないことや同名時の接続判定を保証しません。

## 再検討条件

- 同名機器を個別に選択・維持する要求が生じた場合、または表示名方式で誤選択が発生した場合。
- macOS 実機で同名時の列挙・接続判定の実装を確定する必要が生じた場合。
