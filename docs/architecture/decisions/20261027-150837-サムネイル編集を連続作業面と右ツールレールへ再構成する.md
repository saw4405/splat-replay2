# サムネイル編集を連続作業面と右ツールレールへ再構成する

- ID: 20261027-150837
- 状態: accepted
- 日時: 2026-10-27T15:08:37+09:00
- 判断者: メインエージェント

## 目的・問題

四つの操作目的をカードに分けただけでは、プレビューを主役にした編集の流れと情報の優先順位が伝わらない。前回の四領域構成に対するユーザーの再指摘を受け、操作目的の区分を残したまま、画面を一続きの作業面として組み直す。併せて、背景移動中のぼけ、空白クリック時の選択解除、表示情報の重複、テンプレート変数の確認・コピーを明確にする。

## 前提・制約

- 先行 ADR [20261027-111805](./20261027-111805-サムネイルデザインを共通設定で編集し生成開始時に固定する.md) の保存境界を維持する。子画面の「適用」で実生成サンプルを確認し、「このデザインを使う」で親設定へ戻った後、親画面の「保存」でデザインを確定する。親画面で取消した場合はデザイン変更を破棄する。素材の追加・削除は即時反映し、生成開始時点でデザインを固定する。
- 先行 ADR [20261027-120744](./20261027-120744-実サンプルと共通描画に合わせてサムネイル編集画面を整える.md) の固定サンプル、共通描画と操作範囲の一致、保存済みカスタム設定保持を維持する。
- ADR [20261027-143630](./20261027-143630-サムネイル編集を四領域に分け背景と要素を直接操作する.md) が定めたプレビュー、背景、要素管理、選択要素編集という意味上の操作群と、背景移動・要素選択・文字入力の操作境界を維持する。
- ブラウザコメントに記録された表示領域は 889×864 である。これはコメント時の画面寸法であり、本 ADR による変更後の表示確認が済んだ証拠ではない。
- 本 ADR では実装後の検証完了を主張しない。指定された画面寸法と操作状態での確認は実装側の完了条件とする。

## 判断

1. 四枚のガラス調カードをやめ、プレビューキャンバスを中心とした連続した作業面と、右側の単一ツールレールで構成する。背景設定はキャンバスの下に連続する小さな設定帯として置く。背景、要素管理、選択要素の属性という役割はレール内でも見分けられるように保ち、カードごとの背景や独立した見出し帯に頼らず、配置・余白・控えめな境界で区別する。
2. 見出し帯、装飾、重複する状態表示を減らす。キャンバスの論理サイズは維持し、表示中の「1920 × 1080 px」ラベルは取り除く。表示パターンの切り替えはプレビュー領域内の操作として配置する。「マッチ画像を選択中」など「○○選択中」の状態文言は表示しないが、要素の選択状態と編集機能は維持する。
3. 通常の要素選択モードでは、プレビュー作業面の空白をクリックすると要素選択を解除する。空白には画像の内側と外側を含める。背景移動モード、スポイト、要素のドラッグ、選択用コントロール（セレクト等）は解除処理の対象から除き、それらの操作中や操作終了時のクリックで選択が誤解除されないようにする。
4. 要素名と不透明度は折りたたまず、右側の選択要素編集に常時表示する。
5. テンプレート変数のヒントはテンプレート入力欄の直下で展開できるようにする。変数ごとにコピー操作を設け、コピーする文字列には構文の波括弧を含める。コピー処理の成功・失敗を画面で区別する。
6. 背景移動を含む透明な操作ボタンには、グローバルなぼかし効果と、操作中の縮小効果を適用しない。プレビュー上の操作面が背景移動中にぼけて見えたり、操作対象が縮んで見えたりしないようにする。
7. 画面の配色・要素の種類、設定の保存境界、サムネイルの描画モデルは変更しない。UI の情報配置と、上記で特定した選択・ヒント・コピーの振る舞いだけを変更対象とする。
8. 実装後、889×864 の実画面でレイアウトを確認する。クリップボードの成功・失敗、透明な操作ボタンのぼかし関連 computed style（通常・hover・active・focus 等の状態）、通常モードでの画像内外の空白クリック、および背景移動・スポイト・要素ドラッグ・選択用コントロールとの選択解除の競合を実操作で確認する。これらは未確認であり、完了済みとは扱わない。

## 検討した選択肢と棄却理由

- 四領域それぞれを同じ強さのカードとして残し、角丸や色だけを調整する案は採用しない。ユーザーは単純なグループ分けでは編集の流れが整わないと指摘し、メインエージェントも前案が情報の優先順位を整理できていないと認めた。
- 操作群そのものを一つの無区分な領域へ統合する案は採用しない。プレビュー、背景、要素一覧、選択要素の属性という目的の違いは維持し、視覚表現だけを連続面へ変える。
- 「1920 × 1080 px」や「○○選択中」を残して操作状態を繰り返し文章で説明する案は採用しない。ユーザーは前者を不要とし、後者も不要と指摘した。実際の選択状態やキャンバス寸法は保ち、表示文言だけを整理する。
- 空白クリックを操作モードに関係なく選択解除へ使う案は採用しない。背景移動、スポイト、要素ドラッグ、選択用コントロールの入力と競合するため、通常の選択モードの空白クリックに限定する。
- テンプレート変数名だけをコピーする案は採用しない。入力で使う構文をそのまま貼れるよう、波括弧込みでコピーし、結果を成功・失敗に分けて伝える。

## 適用範囲

- サムネイル編集画面の視覚構成、プレビュー・右ツールレール・背景設定帯の配置。
- 表示パターン、寸法ラベル、選択状態表示、要素名・不透明度の配置。
- プレビュー空白クリックでの要素選択解除と他の操作とのイベント境界。
- テンプレート変数ヒントの配置、展開、コピーと結果表示。
- 透明な操作ボタンのぼかし・操作中の縮小効果、および指定された実画面検証。

## 適用しない範囲

- 子画面の適用・実生成確認、親画面の保存・取消、素材操作の即時反映、生成開始時の設定固定。
- 固定サンプル、共通描画、実出力範囲と選択範囲の一致、保存済みカスタム設定。
- キャンバスの論理寸法、デザイン要素の色・種類、サムネイルの描画モデル。
- 新しい要素種別、編集機能、複数デザイン管理の追加。

## 期待する効果

- プレビューに視線を集め、編集対象に近い場所で背景・要素・属性を操作できる。
- 操作目的の違いを保ちながら、均質なカードと見出しの反復を減らせる。
- 選択解除が通常モードの空白クリックに限られ、背景移動・スポイト・ドラッグ・セレクト操作を妨げない。
- 名前と不透明度が折りたたみ操作なしに見つかり、変数の説明・正確な構文コピーも入力欄の近くで完結する。
- 不要なサイズ・選択状態のラベルを減らし、背景移動時もプレビュー上の透明な操作面を読み取れる。

## 受け入れる欠点・リスク

- 見出しや状態文言を減らすことで、配置だけでは操作群や現在の選択を認識しにくくなる可能性がある。右レール内の役割区分と既存の選択表示が十分か、実画面で確認する。
- 右レールと連続した背景帯は狭い画面で折り返しや縦方向の占有を生む可能性がある。889×864 でキャンバスと主要操作が使えることを確認する。
- 空白クリック解除の対象が広すぎると、他の操作で選択を失う。モードとポインター操作ごとに解除条件を検証する。
- クリップボードが利用できない環境ではコピーに失敗し得る。失敗を成功と表示しないことを確認する。
- 箱状の装飾を減らしても、視覚的に洗練されたこと自体はレイアウトだけでは証明されない。実画面と操作の確認を経て判断する。

## 再検討条件

- 889×864 または小さい表示領域で、キャンバス・主要操作・右レールのいずれかが実用上見えない、または操作できない場合。
- 背景移動・スポイト・要素ドラッグ・選択用コントロール中に意図しない選択解除が起きる場合、または通常モードの空白クリックで解除されない場合。
- 変数コピーの成功・失敗を正しく表示できない、または波括弧を含む構文を再現できない場合。
- 通常・hover・active・focus のいずれかで透明な操作ボタンがプレビューへぼかしや縮小を与える場合。
- カード表現を減らした結果、背景設定や選択要素の属性を見つけにくくなる場合。

## 置換・追補関係

本 ADR は ADR 20261027-143630 の四象限・四カードという視覚的な配置だけを置き換えます。プレビュー、背景、要素管理、選択要素の編集という意味的な操作群、および同 ADR が定めた背景移動モード、選択・文字入力の操作境界は維持します。新たに定めた空白クリック時の選択解除、表示情報の整理、変数コピーはその上に追補します。

ユーザーの「プレビューエリア内に移動して」という訂正に基づき、本 ADR は ADR 20261027-120744 判断 4 のうち表示パターン切り替えの配置を、プレビュー領域の内側へ移す形で部分置換します。固定サンプルを使うこと、実生成画像による確認、その他の保存・表示確認の契約は変更しません。ADR 20261027-111805 の設定保存・取消、素材操作、生成開始時固定にも変更はありません。
